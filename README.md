# Акварельное свадебное приглашение

Статическое двуязычное приглашение RU/KG. ID приглашения берётся из первого сегмента URL, например `/3`.

## Локальный просмотр

```powershell
npm start
```

После запуска откройте `http://127.0.0.1:4173/3`, заменив `3` на существующий ID.

## Данные

- GET: `https://x8ki-letl-twmt.n7.xano.io/api:X8-e2j1w/priglosi/{id}`
- PATCH: `https://x8ki-letl-twmt.n7.xano.io/api:X8-e2j1w/priglosi/{id}/full`

При ошибке API демоданные не используются.
